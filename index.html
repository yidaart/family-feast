红红火火 · 水煮豆花牛肉
硬菜 · 隋卞做法 · 用户自制加豆花
特厨隋卞 BV1pC411Y7ch
🥬 备料（20人估）
  • 牛外脊 — 2kg，顶丝切约1mm薄片
  • 豆花（嫩豆腐） — 8小块（约1.5kg），划大块
  • 莴笋 — 2根，切薄片
  • 豆芽 — 500g，焯水备用
  • 金针菇 — 300g，去根洗净
  • 芹菜 — 150g，切段
  • 干辣椒 — 80g，攥碎，干锅炒香
  • 花椒 — 60g，干锅炒干磨面
  • 小葱·蒜·姜 — 各适量
🔪 切配关键
  • 牛肉顶丝（逆纹）切1mm；可用刀背先砸断纹路再切
  • 冻肉版：冻至半硬切1.5mm，化冻后沥干揪白筋
  • 干辣椒攥碎干锅小火炒香；花椒炒干后磨粗粉
  • 葱姜水：葱段+姜丝泡水，一斤肉配二两多
🥫 调料
  • 腌肉：盐·味精·老抽·食用碱（极少许）·全蛋·稀释水淀粉
  • 汤底：豆瓣酱·辣椒碎·葱姜蒜（留部分）·花椒油底
  • 调味：花椒面·生抽·胡椒粉·味精·糖
  • 泼油：花椒面·辣椒碎·葱花·蒜末·白芝麻，热油六七成热
👨‍🍳 烹饪（隋卞做法）
  • ① 腌肉：盐+味精+老抽+食用碱按摩至粘稠 → 加葱姜水（一斤肉二两多）→ 加全蛋抓匀 → 稀释淀粉挂浆 → 补老抽调色 → 表面封油
  • ② 炒香料油：底油炸花椒后捞出（只用油）
  • ③ 炒底料：小火炒豆瓣酱出红油 → 加葱姜蒜+辣椒碎
  • ④ 煮汤：加水+花椒面+生抽+胡椒粉+味精+糖，大火煮开
  • ⑤ 烫菜铺底：豆芽/金针菇/莴笋焯水铺碗底
  • ⑥ 烫牛肉：大火，汤开后一片片下肉，再次大开后约1min捞出
  • ⑦ 泼油：碗中撒花椒面+辣椒碎+葱花+蒜末，热油六七成热浇上
  1. 切肉：顶丝切1mm（或冻肉1.5mm），化冻沥干揪白筋
  2. 腌肉：盐+味精+老抽+食用碱按摩→葱姜水（一斤肉二两多）→全蛋→淀粉→封油
  3. 干辣椒攥碎炒香，花椒炒干磨面，葱姜蒜分两份
  4. 底油炸花椒捞出 → 小火炒豆瓣酱出红油 → 加葱姜蒜+辣椒碎
  5. 加水+花椒面+生抽+胡椒粉+味精+糖，大火煮开
  6. 蔬菜焯水铺碗底；牛肉片大火下锅，再次大开约1min
  7. 碗中撒香料，热油六七成热浇上，撒芝麻
⚠️
隋卞要点：①牛肉1mm越薄越嫩；②食用碱让肉蓬松，用量极少；③葱姜水是关键，一斤肉二两多；④牛肉再次大开即可，不能煮久；⑤泼油温度六七成热激发香气不焦糊。
⏱ 时间轴：切肉(10min) → 腌肉(10min) → 炒底料(3min) → 煮汤(2min) → 烫菜(2min) → 烫肉(2min) → 泼油(1min) | 约20min + 备料

节节高升 · 油焖罗氏虾
硬菜 · 晓飞歌小龙虾调料
🥬 备料（20人估）
  • 罗氏虾 — 2kg，剪须脚刺，开背去虾线
  • 晓飞歌小龙虾调料 — 1袋（约300-400g）
  • 姜·蒜·葱 — 各30g，切末/葱花
  • 啤酒/清水 — 200ml
  • 色拉油 — 适量
🔪 切配
  • 罗氏虾去虾线：嘴巴处掏进去，去胆囊，腹部剪开
  • 开背（背部划一刀更入味），虾身擦干或沥干
  • 虾身可裹薄淀粉抖掉余粉（也可不裹，直接炒）
  • 晓飞歌小龙虾调料整袋备用
👨‍🍳 烹饪
  • ① 处理：罗氏虾剪须脚刺，开背去虾线，沥干表面
  • ② 炒虾：锅烧热，宽油，下罗氏虾大火翻炒至虾壳变红（约3-4min）盛出备用
  • ③ 炒料：锅留底油，下姜蒜末爆香，倒入晓飞歌小龙虾调料整袋，小火炒出红油（约1-2min）
  • ④ 焖煮：下虾，加啤酒/清水200ml，大火煮开后盖盖小火焖3-5min
  • ⑤ 出锅：撒葱花，出锅
  1. 罗氏虾处理好，晓飞歌小龙虾调料整袋备用
  2. 宽油大火热锅，下虾大火翻炒至壳变红（约3-4min）盛出
  3. 虾盛出，锅留底油，下姜蒜末爆香
  4. 小火炒晓飞歌调料出红油（约1-2min）
  5. 下虾，加啤酒/清水200ml，焖3-5min
  6. 撒葱花出锅
⚠️
虾壳薄，焖时火不能太大，时间控制在3-5min内。晓飞歌调料本身有味，可根据口味决定是否额外加盐。
⏱ 时间轴：处理虾(5min) → 炒虾(3-4min) → 炒料(1-2min) → 焖(3-5min) | 合计约12-15min

大吉大利 · 桑拿鸡
硬菜 · 丝瓜虫草花清蒸
🥬 备料（20人估）
  • 清远鸡/三黄鸡 — 1.2kg，切丝
  • 丝瓜 — 3根，去皮切滚刀块
  • 干虫草花 — 80g，温水泡软沥干
  • 姜·葱 — 各30g，切丝/段
  • 红枣 — 8颗，去核
  • 枸杞 — 20g
🔪 切配
  • 鸡切丝（约5mm，太细蒸完会缩没）
  • 丝瓜去皮，切滚刀块（切大块不然蒸完出水化掉）
  • 虫草花泡软后轻轻攥干水分
  • 鸡丝+姜丝+料酒+盐+生抽+蚝油+淀粉拌匀，腌15min
👨‍🍳 烹饪
  • ① 腌：鸡丝+生抽+蚝油+料酒+盐+淀粉拌匀，腌15min
  • ② 铺盘底：丝瓜块铺盘底，虫草花+红枣+枸杞铺上面
  • ③ 铺鸡丝：腌好的鸡丝均匀铺在菜上，撒姜丝
  • ④ 蒸制：水开后，中大火蒸10-12min（鸡肉变白即熟）
  • ⑤ 出锅：撒葱段，淋少许热油激发香气
  1. 鸡丝切好后加腌料拌匀，腌制15min
  2. 丝瓜铺盘底，虫草花/红枣/枸杞铺在上面
  3. 鸡丝铺顶层，均匀撒开
  4. 水开后上锅，中大火蒸10-12min
  5. 出锅撒葱段，淋一勺热油即可
⚠️
鸡丝不能切太细，蒸时会收缩。丝瓜切大块。高压锅压排骨时，蒸锅同时蒸鸡。
⏱ 时间轴：切鸡丝(8min) → 腌(15min) → 摆盘(5min) → 蒸(10-12min) | 合计约38-40min（与排骨并行）

蒸蒸日上 · 粉蒸排骨
硬菜 · 高压锅版 · 村驴做法
来源：村驴
🥬 备料（20人估）
  • 猪小排 — 2kg，剁4cm小块
  • 蒸肉粉 — 500g（无盐型）
  • 郫县豆瓣 — 80g，剁细
  • 老抽·生抽·料酒 — 各40-60ml
  • 花椒·八角·香叶 — 各适量
  • 姜·葱 — 各30g
🔪 切配
  • 排骨剁4cm小块，冷水浸泡1h去血水
  • 捞出沥干（厨房纸擦干表面）
  • 腌30min：豆瓣+生抽+老抽+料酒+盐+鸡精+姜末拌匀
  • 蒸肉粉撒入，少量加水让粉化开，每块排骨均匀裹粉
    • 裹好粉的排骨放入高压锅，加少许水（刚好没过排骨下方即可）
👨‍🍳 烹饪
  • ① 泡血水：排骨冷水浸泡1h，中途换水1-2次
  • ② 腌排骨：调料拌匀腌30min入味
  • ③ 裹粉：蒸肉粉+少量水拌匀，排骨均匀裹粉
  • ④ 高压锅压：排骨放入高压锅，加少许水，上汽后中火压30-35min
  • ⑤ 出锅：散气后开盖，撒葱花，趁热上桌
  1. 排骨提前冷水泡1h去血水，沥干
  2. 腌料拌匀腌30min
  3. 蒸肉粉加少许水化开，排骨裹粉
  4. 第一个上蒸锅！大火蒸开，中火蒸60min
  5. 出锅撒葱花，趁热上桌
⚠️
高压锅压25-30min，比蒸锅60min更快更入味。压好后不要急开阀，散气后再开。
⏱ 时间轴：泡血水(1h) → 腌(30min) → 裹粉摆盘(8min) → 蒸(60min，最先上锅) | 建议10:00开始备，11:45前上桌

阖家欢乐 · 奥尔良鸡翅煲
配菜 · 山姆新奥尔良风味鸡翅中
山姆半成品 · 娃厂长做法
🥬 备料（20人估）
  • 山姆新奥尔良风味鸡翅中 — 1.2kg（已腌制调味）
  • 啤酒 — 150ml
  • 色拉油 — 80ml
  • 姜片·花椒·蒜粒·干辣椒节·白芝麻 — 各适量
🔪 切配
  • 山姆鸡翅已预先腌制，无需再腌
  • 取出鸡翅回温约5min，吸干表面水分
👨‍🍳 烹饪
  • ① 砂锅微温：砂锅烧热至约50°C（手摸微温）
  • ② 入翅：倒入鸡翅+啤酒+姜片+花椒+蒜粒+辣椒节，小火煎两面金黄（约5min）
  • ③ 焖煮：盖盖小火焖3-5min
  • ④ 收汁：开大火，收汁至浓稠
  • ⑤ 出锅：撒白芝麻，装盘
  1. 山姆鸡翅回温，吸干表面水分
  2. 砂锅微温入料（不能烧热，会焦底）
  3. 倒入鸡翅+啤酒+姜片+花椒+蒜粒+辣椒节，小火煎两面金黄
  4. 小火焖3-5min，开大火收汁
  5. 撒芝麻出锅
⚠️
山姆鸡翅已调味，不需要奥尔良腌料和黑鸭煲酱，加啤酒和香料提味即可。1.2kg约20个鸡翅，刚好20人每人1个。建议最后做，上桌前15min开始。
⏱ 时间轴：回温(5min) → 煎(5min) → 焖(3-5min) → 收汁(2min) | 合计约15-17min（最后做）

和和美美 · 娃娃菜炒火腿肠
配菜 · 家常做法
🥬 备料（20人估）
  • 娃娃菜 — 8颗（约2.5kg），切大块或条
  • 火腿肠 — 15根（约750g），切斜片
  • 大蒜·姜·小红椒 — 各适量
🔪 切配
  • 娃娃菜洗净，竖切两半，再切大块
  • 火腿肠斜切成片（约5mm厚）
  • 蒜末+姜末+辣椒圈备好
👨‍🍳 烹饪
  • ① 热锅凉油：大火，油温七成热
  • ② 爆香：下蒜末+姜末+辣椒，爆香（约15s）
  • ③ 炒火腿：下火腿肠，中火翻炒至表面微焦（约2min）
  • ④ 炒娃娃菜：大火，下娃娃菜快炒，菜叶一软塌即刻（约2min）
  • ⑤ 调味：加蚝油+生抽+白糖+盐，翻匀出锅
  1. 娃娃菜切大块，火腿肠斜切
  2. 油热后下蒜姜末+辣椒，爆香
  3. 下火腿肠煎至表面微黄
  4. 大火下娃娃菜，全程大火快炒不超过40s
  5. 调味后出锅，不能盖盖，保持翠绿
⚠️
全程大火快炒，娃娃菜炒太久会出水变黄。简单菜，适合与其他大菜并行操作。
⏱ 时间轴：切配(3min) → 爆香(15s) → 煎肠(2min) → 炒菜(2min) | 合计约7min，全程大火

金玉满堂 · 厚切炸猪排
配菜 · 山姆厚切炸猪排半成品
🥬 备料（20人估）
  • 山姆厚切炸猪排 — 1kg（已调味裹粉，开袋即炸）
  • 卷心菜 — 半颗，细切丝，铺底
  • 猪排酱/美乃滋 — 蘸酱用
  • 空气炸锅 — 1台，铺烘焙纸
🔪 切配
  • 卷心菜切细丝，铺盘底备用
  • 猪排从冰箱取出，恢复室温约10min
  • 山姆猪排已调味裹粉，无需再裹粉
  • 空气炸锅铺烘焙纸，180°C预热5min
👨‍🍳 烹饪
  • ① 预热：空气炸锅180°C预热5min
  • ② 炸制：猪排平铺不叠，180°C炸10-12min（中途翻面一次）
  • ③ 出锅：炸至金黄酥脆，吸油纸吸干，摆在卷心菜丝上，配猪排酱
  1. 卷心菜切细丝铺盘底
  2. 猪排室温回软10min
  3. 空气炸锅180°C预热5min，猪排平铺
  4. 180°C炸10-12min，中途翻面一次
  5. 炸至金黄，吸油纸吸干，配猪排酱上桌
⚠️
山姆猪排已调味裹粉，开袋即炸。1kg约6-8片，20人每人约1片，刚好够。和炸鸡可共用空气炸锅分批。
⏱ 时间轴：切菜丝(5min) → 回软(10min) → 炸10-12min | 合计约15min

喜庆团圆 · 派对炸鸡组合
配菜 · 山姆泰森半成品
🥬 备料（20人估）
  • 山姆泰森派对炸鸡组合 — 2份（1.2kg×2 = 2.4kg）
  • 油 — 足量，炸制用
  • 吸油纸·番茄酱·蜂蜜芥末·甜辣酱 — 各适量
🔪 切配
  • 炸鸡从冰箱取出，恢复室温约10min
  • 烤盘铺吸油纸备用
  • 大托盘装盘，配三种蘸酱分格放
👨‍🍳 烹饪
  • ① 热油：油温烧至七成热
  • ② 炸制：分批下炸鸡，中火炸5-6min至金黄
  • ③ 控油：捞出放吸油纸上沥油1min
  • ④ 摆盘：大托盘摆盘，三种酱分格跟上
  1. 炸鸡室温回软，油温烧至七成热
  2. 分批下锅，中火炸5-6min至表面金黄酥脆
  3. 捞出放吸油纸上沥油
  4. 大托盘摆盘，配三种蘸酱
